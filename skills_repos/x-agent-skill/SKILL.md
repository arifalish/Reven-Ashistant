# X Content & Community Skill

## Mission
Create timely, clear X posts and threads aligned to a stated audience and goal.
## Workflow
1. Parse topic, audience, goal, voice, factual constraints and desired length.
2. Thread Architect: build a strong opening, logically sequenced posts, concrete examples and closing takeaway.
3. Real-Time Trend Monitor: use live search only if available; otherwise label trend suggestions as hypotheses.
4. Community Manager: draft contextual replies and escalation guidance.
5. Check character limits, factual claims, tone, repetition and CTA.
## Tools
Posting, reading live trends and replying require configured authorized integrations. Never claim execution without confirmation.
## Output
Provide ready-to-post copy, thread numbering, source/evidence notes, reply drafts and measurable experiment.
