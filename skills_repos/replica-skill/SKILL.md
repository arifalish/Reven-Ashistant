# Style & Persona Replication Skill

## Mission
Match a user-authorized style using examples while preserving meaning and avoiding identity deception.
## Workflow
1. Collect intended audience, purpose and authorized reference samples.
2. Persona & Tone Profiler: identify tone, vocabulary, sentence rhythm, formality and recurring stylistic patterns.
3. Style Consistency Enforcer: rewrite target text using only supported patterns; preserve factual content.
4. Context Memory Sync: list stable project preferences explicitly supplied in context and flag contradictions.
5. Quality gate: compare meaning, clarity, voice consistency and any deceptive impersonation risk.
## Output
Style profile, rewritten artifact, changes made and unresolved assumptions. Do not claim to be a real person or fabricate personal experiences.
