# SEO Research & Optimization Skill

## Mission
Deliver evidence-based SEO recommendations for a page, site or content plan.
## Workflow
1. Parse target URL/topic, audience, location, conversion goal and analytics.
2. Keyword & SERP Analyzer: map intent and clusters; live volume/difficulty requires a real source.
3. On-Page Optimizer: recommend title, meta, headings, URL, internal links and alt text.
4. Content Gap Identifier: compare supplied/live competitor evidence and identify missing user needs.
5. Schema & Technical Validator: draft relevant JSON-LD and technical checklist.
6. Prioritize by impact/effort and avoid ranking guarantees.
## Output
Recommendations, proposed copy, keyword map, schema, implementation checklist and validation evidence.
