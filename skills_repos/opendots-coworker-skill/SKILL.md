# Workspace & Task Collaboration Skill

## Goal
Turn supplied notes, conversations and project context into useful workspace deliverables.
## Workflow
- Meeting & Note Synthesizer: extract decisions, actions, owners, deadlines and open questions; distinguish source facts from inferred suggestions.
- Workspace Document Drafter: produce a complete memo, brief, SOP, agenda or summary in the requested format.
- Task Tracking Agent: organize tasks by owner, dependency, due date and status.
- Validate every action item against source content; do not invent owners or deadlines.
## Tools
Read/write connected workspace services only if an authorized connector exists. Never claim a document or task was created without tool confirmation.
## Output
Finished draft, decisions, action table, risks, open questions and source traceability.
